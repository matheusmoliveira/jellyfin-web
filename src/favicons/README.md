# 📁 Favicons - Play TV

Coloque seus arquivos de favicon aqui.

## Arquivos Necessários:

- `favicon.ico` - Ícone padrão (multi-resolução)
- `touchicon.png` - 180x180 (Apple Touch Icon)
- `touchicon72.png` - 72x72
- `touchicon114.png` - 114x114
- `touchicon144.png` - 144x144
- `touchicon512.png` - 512x512

## Como Gerar:

Veja o arquivo `GUIA_FAVICONS.md` na raiz do projeto para instruções detalhadas.

## Mapeamento Rápido:

Se você gerou com RealFaviconGenerator:
- `favicon.ico` → use direto
- `apple-touch-icon.png` → renomeie para `touchicon.png`
- Gere os outros tamanhos (72, 114, 144, 512) a partir do `apple-touch-icon.png`
